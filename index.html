What it does

Plug in your iPhone, run one command, and every new photo and video lands in the right place — organized by the date it was taken.

Reads originals off the phone

Talks to a USB-connected iPhone through Apple’s ImageCaptureCore framework — full-resolution HEIC/JPEG/MOV, not re-compressed copies.

Dated folders by year

Photos and videos are filed into YYYY/YYYY-MM-DD/ using the true EXIF “date taken” (via exiftool), with sensible fallbacks.

Two tidy trees

Photos go to a Pictures share, videos to a Videos share — each on an SMB-mounted SSD, auto-mounted before every run.

Non-destructive

Nothing is ever deleted from the iPhone. The phone stays your source of truth.

Incremental

Already-imported files are skipped by name + date folder — without even downloading them — so re-runs are fast.

Smart about edge cases

Screenshots kept as photos; Live-Photo motion clips skipped; files with no metadata land in Unknown-Date/.

How a run works

A small pipeline of focused, testable stages.

01

Mount

Auto-mounts both SMB shares from .env; verifies exiftool before any download.

02

Discover

Finds the connected iPhone via ImageCaptureCore and lists files with names + dates.

03

Plan

Classifies photo vs video, drops Live-Photo motion, skips already-imported files.

04

Pull & date

Downloads new originals to staging; exiftool decides the authoritative date.

05

File

Moves each file into <share>/YYYY/YYYY-MM-DD/ and reports the totals.

Quick start

macOS with an iPhone on USB, an SMB share on your SSD, and Xcode’s ImageCaptureCore available.

# install
python3 -m pip install -r requirements.txt
brew install exiftool

# configure (copy the example, then fill in your SMB details)
cp .env.example .env

# preview without writing anything, then import for real
python3 import_photos.py --dry-run
python3 import_photos.py --verbose

Config lives in a git-ignored .env (SMB host, user, password, share names). The first run triggers a macOS prompt to access the iPhone — grant it, and tap “Trust” on the phone.

Under the hood

Testable core

Classification, Live-Photo pairing, date-folder selection and dedup are pure functions behind a PhotoSource seam — 34 passing tests, no phone required.

Python 3 + PyObjC

All-Python: PyObjC drives ImageCaptureCore directly, so there’s no separate helper binary and no manual export step.

exiftool for dates

The gold standard for reading “date taken” out of HEIC, MOV and PNG — the authority for where each file is filed.
